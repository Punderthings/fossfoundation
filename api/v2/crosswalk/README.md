# Foundation platform crosswalk exports

Generated by `fdncrosswalk export` from `_data/crosswalk/`; do not edit by hand. Field meanings and
the standards each field maps to: https://fossfoundation.info/crosswalk

- `<foundation>.json`: one foundation's crosswalk as JSON-LD, with computed confidence.
- `context.jsonld`: JSON-LD context mapping keys to Schema.org, Dublin Core, PROV-O and `fdn:` terms.
- `vocab.jsonld`: RDFS definitions of the `fdn:` terms.
- `stewards.jsonl`: one line per confirmed or probable link, keyed as ecosyste.ms names things.
